   43: =head1 DESCRIPTION
   44: 
   45: C<Email::Abuse::Investigator> examines the raw source of a spam/phishing e-mail
   46: and answers the questions manual abuse investigators ask:
   47: 
   48: =over 4
   49: 
   50: =item 1. Where did the message really come from?
   51: 
   52: Walks the C<Received:> chain, skips private/trusted IPs, and identifies the
   53: first external hop.  Enriches with rDNS, WHOIS/RDAP org name and abuse
   54: contact.  Both IPv4 and IPv6 addresses are supported.
   55: 
   56: =item 2. Who hosts the advertised web sites?
   57: 
   58: Extracts every C<http://> and C<https://> URL from both plain-text and HTML
   59: parts, resolves each hostname to an IP, and looks up the network owner.
   60: 
   61: =item 3. Who owns the reply-to / contact domains?
   62: 
   63: Extracts domains from C<mailto:> links, bare e-mail addresses in the body,
   64: the C<From:>/C<Reply-To:>/C<Sender:>/C<Return-Path:> headers, C<DKIM-Signature: d=>
   65: (the signing domain), C<List-Unsubscribe:> (the ESP or bulk-sender domain), and the
   66: C<Message-ID:> domain.  For each unique domain it gathers:
   67: 
   68: =over 8
   69: 
   70: =item * Domain registrar and registrant (WHOIS)
   71: 
   72: =item * Web-hosting IP and network owner (A record -> RDAP)
   73: 
   74: =item * Mail-hosting IP and network owner (MX record -> RDAP)
   75: 
   76: =item * DNS nameserver operator (NS record -> RDAP)
   77: 
   78: =item * Whether the domain was recently registered (potential flag)
   79: 
   80: =back
   81: 
   82: =back

 4299:         +-- A/AAAA record --> web hosting IP --> RDAP --> org + abuse contact
 4300:         |
 4301:         +-- MX record --> mail server hostname --> A --> RDAP --> org + abuse
 4302:         |
 4303:         +-- NS record --> nameserver hostname  --> A --> RDAP --> org + abuse
 4304:         |
 4305:         +-- WHOIS (TLD whois server via IANA referral)
 4306:                +-- Registrar name + abuse contact
 4307:                +-- Creation date  (-> recently-registered flag if < 180 days)
 4308:                +-- Expiry date    (-> expires-soon or expired flags)
 4309: 
 4310: Domains are collected from:
 4311: 
 4312:     From:/Reply-To:/Sender:/Return-Path: headers
 4313:     DKIM-Signature: d=  (signing domain)
 4314:     List-Unsubscribe:   (ESP / bulk sender domain)
 4315:     Message-ID:         (often reveals real sending platform)
 4316:     mailto: links and bare addresses in the body
 4317: 
 4318: =head1 CACHING
 4319: 
 4320: Two levels of caching are used:
 4321: 
 4322: =over 4
 4323: 
 4324: =item Per-message cache (C<$self-E<gt>{_domain_info}>)
 4325: 
 4326: Stores domain analysis results for the lifetime of one C<parse_email()>
 4327: call.  Invalidated by each call to C<parse_email()>.
 4328: 
 4329: =item Cross-message cache (CHI Memory driver, if C<CHI> is installed)
 4330: 
 4331: Stores IP WHOIS, DNS resolution, and domain analysis results across all
 4332: messages processed by the same process.  TTL is one hour.  Prevents
 4333: redundant WHOIS queries for infrastructure that appears in multiple
 4334: messages in the same run (e.g. a sending ISP seen in 500 spam messages).
 4335: 
 4336: =back
 4337: 
 4338: =head1 IPV6 SUPPORT
 4339: 
 4340: IPv6 addresses are extracted from C<Received:> headers using bracketed
 4341: notation (C<[2001:db8::1]>).  They are tested against the private range
 4342: list (which covers ::1, fe80::/10, fc00::/7, fd00::/8, and the
 4343: documentation range 2001:db8::/32) and passed through C<_whois_ip()> and
 4344: C<_rdap_lookup()> in the same way as IPv4 addresses.
 4345: 
 4346: C<_resolve_host()> attempts both A and AAAA lookups when C<Net::DNS> is
 4347: installed.  C<_raw_whois()> uses C<IO::Socket::IP> for dual-stack WHOIS
 4348: connections when that module is installed.
